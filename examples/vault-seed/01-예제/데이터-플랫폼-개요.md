# 데이터 플랫폼 개요

온프레미스 빅데이터 클러스터에서 Kubernetes 기반 Lakehouse/DataOps 플랫폼으로
전환하는 과정을 가정한 예시 아키텍처입니다. 스토리지, 쿼리 엔진, 메타데이터,
배포 자동화까지 컴포넌트 간 의존 관계(`depends_on`)와 장애 기록(`affects`)으로
표현했습니다.
