# 마크다운 작성 가이드

VaultViewer에서 노트를 쓸 때 알아두면 좋은 문법과 관례를 정리했습니다.
`기능 둘러보기`가 한눈에 보는 맛보기였다면, 이 노트는 각 문법을 조금 더
자세히 설명합니다.

## 프론트매터

노트 맨 앞의 `---`로 둘러싼 부분입니다. 세 필드를 씁니다.

```
---
title: 노트 제목
type: note
tags:
  - 태그1
  - 태그2
---
```

- `title` — 화면에는 파일명이 표시되므로 필수는 아니지만, 검색·정리용으로
  적어두면 좋습니다.
- `type` — `그래프` 탭에서 노트 색을 결정합니다. 값은 자유입니다 — 예:
  `note`, `guide`, `project`, `person`, `incident`. 같은 종류의 노트에는
  같은 타입을 붙이면 그래프에서 한눈에 구분됩니다.
- `tags` — `태그` 탭에서 태그별로 노트를 모아 볼 수 있습니다. 리스트(`- 값`)
  형식으로 여러 개를 붙일 수 있습니다.

프론트매터가 없어도 노트는 정상적으로 동작합니다.

## 제목

`#`, `##`, `###`... 로 씁니다. 표준 마크다운과 동일합니다.

## 위키링크 — 다른 노트로 연결

```
[[노트이름]]
[[노트이름|화면에 보일 텍스트]]
```

- 확장자(`.md`)는 생략합니다.
- 같은 폴더에 있는 노트는 이름만 적으면 찾습니다. 다른 폴더의 노트를
  가리키려면 `01-예제/두번째-노트`처럼 경로를 적습니다.
- 어떤 노트를 클릭해서 이 노트로 들어왔다면, 그 관계는 이 노트 하단
  "백링크" 섹션에 자동으로 나타납니다 — 직접 관리할 필요 없습니다.
- `그래프` 탭에서는 위키링크가 실제 연결선으로 그려집니다. 아직 만들지
  않은 노트를 링크로 걸면(예: [[아직-없는-노트]]) 그래프에 점선 원으로
  표시됩니다 — 나중에 그 이름으로 노트를 만들면 자동으로 연결됩니다.

## 이미지 — 노트에 그림 넣기

편집 화면 우측 상단의 "이미지 추가" 버튼을 쓰는 게 가장 쉽습니다. 파일을
고르면 자동으로 `attachments/` 폴더에 올라가고, 커서 위치에 아래 문법이
삽입됩니다.

```
![[파일명.png]]
```

`attachments/` 폴더는 왼쪽 트리에서 자동으로 숨겨지므로, 이미지를 아무리
많이 모아도 노트 구조가 지저분해지지 않습니다. 편집 중에 실제로 어떻게
보이는지 확인하려면 편집 화면의 "미리보기" 버튼을 눌러보세요.

## 콜아웃 — 강조 박스

인용문(`>`) 첫 줄에 `[!타입]`을 붙이면 색이 있는 강조 박스로 바뀝니다.

```
> [!info] 참고
> 이 안에 원하는 내용을 씁니다. 여러 줄도 가능합니다.
```

지원하는 타입:

| 타입 | 용도 |
|---|---|
| `info`, `note` | 참고 정보 |
| `tip`, `hint` | 팁 |
| `warning`, `caution` | 주의 |
| `danger`, `error` | 위험/오류 |
| `success`, `done`, `check` | 완료/성공 |
| `question`, `help` | 질문 |
| `bug` | 버그 |
| `example` | 예시 |
| `quote`, `abstract`, `summary` | 인용/요약 |
| `todo` | 할 일 |

제목(`[!타입]` 뒤 텍스트)은 생략해도 됩니다 — 그러면 타입 이름만 뱃지로
나타납니다.

## 표

표준 GFM 표 문법을 그대로 씁니다.

```
| 역할 | 권한 |
|---|---|
| adm | 읽기·쓰기·삭제 |
| view | 읽기 전용 |
```

## 코드와 다이어그램

인라인 코드는 `` `백틱` ``, 여러 줄은 ```` ``` ```` 로 감쌉니다. 언어를
`mermaid`로 지정하면 텍스트 대신 실제 다이어그램으로 그려집니다.

````
```mermaid
flowchart LR
    A[노트 작성] --> B[위키링크 연결]
    B --> C[그래프 뷰에서 확인]
```
````

## 정리하면

- 노트 사이는 `[[위키링크]]`로 연결 — 백링크·그래프는 자동으로 따라옵니다.
- 이미지는 "이미지 추가" 버튼으로 — 경로를 직접 신경 쓸 필요 없습니다.
- `type`은 그래프 색, `tags`는 태그 탭 — 둘 다 선택 사항이지만 노트가
  많아질수록 정리에 도움이 됩니다.
