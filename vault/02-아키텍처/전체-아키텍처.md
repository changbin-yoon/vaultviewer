# 전체 시스템 아키텍처

> [!tip] 그림 우선
> 실제 구성에 맞게 아래 mermaid를 수정하거나 이미지를 `attachments/`에 넣고 첨부하세요.

```mermaid
flowchart TB
    subgraph External["외부/유입"]
        USER[사용자/분석가]
        SRC[데이터 소스]
    end
    subgraph K8s["Kubernetes Cluster"]
        ING[Ingress / LB]
        subgraph Workloads["주요 워크로드"]
            SPARK[Spark on K8s]
            TRINO[Trino]
            AIRFLOW[Airflow]
        end
        MON[Prometheus / Grafana]
    end
    subgraph Storage["스토리지"]
        S3[(Object Storage MinIO/AIStor)]
        CEPH[(Ceph)]
        ISILON[(Isilon)]
        HDFS[(HDFS - 레거시)]
    end
    USER --> ING --> Workloads
    SRC --> S3
    AIRFLOW --> SPARK
    SPARK --> S3
    SPARK --> CEPH
    TRINO --> S3
    TRINO --> ISILON
    SPARK -.레거시.-> HDFS
    MON -.-> Workloads
```
