# 스토리지 도입, 평가, 이관 (2024~2026)

- 스토리지 성능 테스트(fio): Isilon(SSD/HDD), Ceph(RBD/CephFS)를 RWO/RWX 2가지 모드로 순차/랜덤/IOPS 측정, 비교 → 운영 스토리지는 Isilon 기반으로 선정, 결과 기반 StorageClass 구성
- Rook-Ceph 설치, 테스트, External Ceph 연동, CSI-RBD/CSI-CephFS 드라이버, StorageClass 생성
- MinIO/AIStor(객체 스토리지) 구축, 버전 업그레이드: HDFS → MinIO 데이터 이관, DirectPV 디스크 구성, AirGapped 설치 런북/가이드 작성, 시스템별(Dev/Prd) 권한 정책(MinIO Policy) 구성 및 운영
- HDFS→MinIO 객체 스토리지 이관(S3A, jceks Credential 암호화), 샘플 데이터 이관 및 PoC, 성능 테스트 진행
